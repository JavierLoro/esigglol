# Evidencia 05 — Ranking, comparador y detalles

- `/ranking`: tabla cargada, búsqueda `gohh`, filtros de rol y checkbox de suplentes; mensaje de datos parcialmente no disponibles.
- `/comparar`: métricas Freakpay/Factor Terminal y validación al seleccionar el mismo equipo.
- `/equipos/{id}`: titulares/suplentes, estados sin datos Riot y botones de estadísticas.
- `/partidos/{id}`: detalle de partido QA con estado Finalizado, marcador 1–0 y `Partida 1 · Sin datos`.
