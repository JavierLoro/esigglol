# Evidencia 06 — Responsive y bloqueos

- Viewport de escritorio capturado y revisado visualmente.
- El browser runtime seleccionado no expone capability de viewport; no se pudo cambiar a 390×844 o 360×768 sin abrir otra superficie. Responsive móvil queda bloqueado con esta limitación exacta.
- Las acciones de borrado se localizaron, pero el runtime exige confirmación inmediata justo antes de borrar; quedaron bloqueadas y no se alteraron más registros.
